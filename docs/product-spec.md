# 홈트레이닝 성장형 웹페이지 기획서
> 목적: Codex가 이 문서를 기반으로 **운동 초보자가 단계별로 성장할 수 있는 저항운동 중심 홈트레이닝 웹페이지**를 구현할 수 있도록 요구사항과 콘텐츠를 구조화한다.

---

## 1. 프로젝트 개요

### 1.1 프로젝트 목적
사용자가 유튜브 영상을 매번 따라 하는 방식이 아니라, 각 운동 패턴을 **Lv.0 → Lv.N 형태의 스킬트리/성장표**로 진행하며 자신의 현재 수준과 다음 목표를 명확히 확인할 수 있는 홈트레이닝 웹페이지를 만든다.

핵심 경험은 다음과 같다.

1. 운동 시작 전에 무엇을 준비해야 하는지 확인한다.
2. 각 운동의 현재 레벨을 확인한다.
3. 해당 레벨의 정확한 운동 방법과 목표 반복 수를 확인한다.
4. 세트 간 휴식 시간을 확인한다.
5. 목표 기준을 충족하면 다음 레벨을 해금한다.
6. 운동 수행 기록을 남겨 성장 과정을 확인한다.

### 1.2 사용자 특성
- 남성
- 만 33세
- 키 172cm
- 체중 약 96.5kg
- 현재 운동 경험이 거의 없는 초보자
- 좌식 생활 비중이 높음
- 보유 장비
  - 5kg 덤벨 2개
  - 푸시업바
  - 문틈철봉
- 목적
  - 체지방 감량과 함께 근육량 최대한 보존
  - 단순 다이어트 홈트가 아니라 **실제 근력 향상**
  - 쉬운 동작에서 시작해 고급 맨몸 동작까지 성장
  - 운동 수행 능력이 숫자로 보이는 구조 선호

### 1.3 운동 프로그램 설계 원칙
ACSM 2026 저항운동 가이드라인의 방향을 참고한다.

- 홈트레이닝, 맨몸운동, 덤벨 모두 유효한 저항운동 수단으로 취급
- 복잡한 루틴보다 **지속성 + 점진적 과부하(progressive overload)** 우선
- 주요 근육군을 반복적으로 훈련
- 매 세트 근육 실패 지점까지 갈 필요 없음
- 초보자는 대체로 **RIR 2~3** 정도의 여유를 남기고 종료
- 세트 간 휴식은 고정된 하나의 숫자보다 **다음 세트에서 자세와 수행을 유지할 수 있을 정도**로 확보
- 초보자는 운동 전 긴 정적 스트레칭보다 **동적 워밍업 + 쉬운 버전의 워밍업 세트** 우선

> 주의: 아래의 구체적인 휴식시간과 반복 수는 ACSM이 모든 사람에게 동일하게 명령하는 수치가 아니라, 초보자가 실제로 실행하기 쉽도록 프로그램에 적용한 실무 기준이다.

# 2. 웹페이지 핵심 UX

## 2.1 메인 화면
메인 화면에서 다음 6개 운동 카테고리를 카드 형태로 보여준다.

1. PUSH — 가슴 / 삼두
2. PULL — 등 / 이두
3. SQUAT — 대퇴사두 / 둔근
4. HIP HINGE — 햄스트링 / 둔근 / 후면사슬
5. VERTICAL PUSH — 어깨 / 삼두
6. CORE — 복부 / 몸통 안정성

각 카드에는 다음 정보를 표시한다.

- 카테고리명
- 현재 레벨
- 현재 수행 중인 운동
- 다음 레벨 운동
- 레벨업까지 남은 조건
- 최근 최고 기록
- `운동 시작` 버튼

예시:

```text
PUSH
현재 Lv.3
일반 푸시업

최근 기록
15 / 13 / 12

다음 레벨
Lv.4 디클라인 푸시업

레벨업 조건
15 / 15 / 15 + RIR 1~2

[운동 시작]
```

## 2.2 운동 상세 화면
운동 상세 화면은 아래 순서로 구성한다.

1. 오늘 수행할 운동명
2. 현재 레벨 / 다음 레벨
3. 운동 시작 전 공통 워밍업
4. 해당 종목 전용 워밍업
5. 본 운동 자세 설명
6. 세트 × 반복 목표
7. 세트 간 휴식 타이머
8. 세트별 실제 수행 기록 입력
9. RIR 기록
10. 세션 종료
11. 레벨업 가능 여부 자동 판정

# 3. 공통 워밍업

모든 운동 전에 약 5분 정도 시행한다.

| 순서 | 동작 | 수행 방법 |
|---|---|---|
| 1 | 제자리 걷기 | 60초 |
| 2 | 팔 앞뒤로 크게 돌리기 | 앞으로 10회 + 뒤로 10회 |
| 3 | 팔 벌려 가슴 열고 닫기 | 10~15회 |
| 4 | 골반 원 그리기 | 좌우 각 8~10회 |
| 5 | 맨몸 굿모닝 | 10회 |
| 6 | 맨몸 스쿼트 | 천천히 8~10회 |

### 워밍업 강도
- 약 RPE 2~3/10
- 땀을 많이 내는 것이 목적이 아님
- 몸의 온도를 올리고 관절을 움직이며 본 운동 자세를 준비하는 것이 목적

# 4. 운동별 성장표

---

# 4.1 PUSH
## 목표 부위
- 가슴
- 삼두
- 전면 어깨

## 장기 목표
일반 푸시업 → 디클라인 → 아처 → 원암 푸시업

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 벽 푸시업 | 15회 × 3세트 |
| 1 | 높은 인클라인 푸시업 | 15회 × 3세트 |
| 2 | 낮은 인클라인 푸시업 | 12~15회 × 3세트 |
| 3 | 일반 푸시업 | 10~15회 × 3세트 |
| 4 | 디클라인 푸시업 | 8~12회 × 3세트 |
| 5 | 아처 푸시업 | 좌우 5~8회 × 3세트 |
| 6 | 보조 원암 푸시업 | 좌우 5~8회 × 3세트 |
| 7 | 원암 푸시업 | 좌우 3~5회 이상 |

## 전용 워밍업
1. 팔 원 그리기
   - 작은 원 5회
   - 큰 원 5회
2. 벽 슬라이드 8~10회
3. 스캐풀라 푸시업 8~10회
4. 현재 레벨보다 쉬운 푸시업 5~8회

예시:
- 현재 일반 푸시업이면 인클라인 푸시업 5~8회 후 본세트 시작

## 세트 간 휴식
- 쉬운 단계: 60~90초
- 일반적인 단계: 90~120초
- 디클라인, 아처 등 고난도: 2~3분 가능

## 푸시업 자세 핵심
- 머리부터 발끝까지 몸통 일직선
- 엉덩이가 과하게 내려가거나 올라가지 않게 유지
- 팔꿈치를 몸통과 완전히 90도로 벌리지 않음
- 가슴이 바닥 쪽으로 내려가도록 충분한 가동범위 확보
- 올라올 때 허리가 먼저 꺾이지 않도록 복부와 둔근에 힘 유지

## 흔한 실수
- 목만 먼저 내려가기
- 허리 꺾임
- 반동 사용
- 반복 수를 늘리려고 가동범위를 줄이는 행동

---

# 4.2 PULL
## 목표 부위
- 광배근
- 등 상부
- 이두
- 전완

## 장기 목표
매달리기 → 스캐풀라 풀업 → 보조 풀업 → 네거티브 → 친업 → 풀업 → 고급 풀업

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 발 보조 매달리기 | 30초 × 3세트 |
| 1 | 데드행 | 30~45초 × 3세트 |
| 2 | 스캐풀라 풀업 | 8~10회 × 3세트 |
| 3 | 발 보조 풀업 | 8~12회 × 3세트 |
| 4 | 네거티브 풀업 | 5초 하강 × 5회 × 3세트 |
| 5 | 친업 | 5~8회 × 3세트 |
| 6 | 정자세 풀업 | 5~8회 × 3세트 |
| 7 | 체스트 투 바 | 5~8회 × 3세트 |
| 8 | 아처 풀업 진행 | 좌우 3~5회 |

## 전용 워밍업
1. 팔 앞뒤 흔들기 10회
2. 벽 슬라이드 8회
3. 견갑골 뒤로 모으기 10회
4. 발을 바닥에 둔 상태로 철봉 잡고 체중 가볍게 싣기
   - 10초 × 2
5. 현재 레벨보다 쉬운 당기기 3~5회

## 세트 간 휴식
- 기본값: 2분
- 네거티브 / 친업 / 풀업: 2~3분
- 다음 세트에서 수행 횟수가 급격히 떨어진다면 휴식 증가

## 풀업 자세 핵심
- 반동 없이 시작
- 어깨가 귀 쪽으로 계속 올라가 있지 않도록 견갑 조절
- 턱만 억지로 철봉 위로 넘기지 않음
- 몸을 과하게 젖혀 치팅하지 않음
- 내려올 때도 통제

## 철봉 안전
- 매번 운동 전 철봉 설치 상태 확인
- 제품 허용하중 확인
- 처음부터 점프해서 매달리지 않음
- 발을 바닥에 둔 상태에서 서서히 하중을 걸어 흔들림 확인

## 보조운동
### 원암 덤벨 로우 5kg
풀업 수준이 낮은 동안 등 근육 보조운동으로 활용한다.

난도 증가 방식:
1. 반복 수 증가
2. 상단 2초 정지
3. 하강 3초
4. 반복 수 15~20회
5. 추후 중량 증가

# 4.3 SQUAT
## 목표 부위
- 대퇴사두근
- 둔근

## 장기 목표
양발 스쿼트 → 런지 → 불가리안 스플릿 → 피스톨 스쿼트

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 의자 스쿼트 | 15회 × 3세트 |
| 1 | 맨몸 스쿼트 | 15~20회 × 3세트 |
| 2 | 5kg 고블릿 스쿼트 | 15회 × 3세트 |
| 3 | 10kg 덤벨 스쿼트 | 12~15회 × 3세트 |
| 4 | 리버스 런지 | 좌우 10~12회 × 3세트 |
| 5 | 불가리안 스플릿 스쿼트 | 좌우 8~12회 × 3세트 |
| 6 | 덤벨 불가리안 스플릿 스쿼트 | 좌우 8~12회 × 3세트 |
| 7 | 박스 피스톨 스쿼트 | 좌우 5~8회 × 3세트 |
| 8 | 피스톨 스쿼트 | 좌우 5회 이상 |

## 전용 워밍업
1. 발목 무릎 밀기(Ankle Rock)
   - 좌우 10회
2. 골반 원 그리기
   - 좌우 8회
3. 의자 스쿼트 또는 맨몸 스쿼트
   - 8회
4. 바닥 자세에서 1초 멈추는 맨몸 스쿼트
   - 5회

## 세트 간 휴식
- 맨몸 단계: 약 90초
- 덤벨 스쿼트 / 런지: 90~150초
- 불가리안 / 피스톨: 2~3분

## 좌우 운동 세트 계산
```text
왼쪽 수행
→ 오른쪽 수행
→ 휴식
= 1세트
```

## 스쿼트 자세 핵심
- 발바닥 전체가 바닥에 닿도록 유지
- 무릎은 발끝 방향과 유사하게 움직임
- 내려갈 때 무릎이 안쪽으로 심하게 붕괴하지 않도록 함
- 허리를 억지로 세우기보다 자연스러운 척추 중립 유지
- 깊이는 통증 없이 자세가 유지되는 범위

# 4.4 HIP HINGE
## 목표 부위
- 햄스트링
- 둔근
- 척추기립근을 포함한 후면사슬

## 장기 목표
힙힌지 습득 → RDL → 편측 RDL

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 맨몸 힙힌지 | 15회 × 3세트 |
| 1 | 글루트 브리지 | 15~20회 × 3세트 |
| 2 | 덤벨 RDL 10kg | 12~15회 × 3세트 |
| 3 | 3초 하강 RDL | 12~15회 × 3세트 |
| 4 | B-스탠스 RDL | 좌우 10~12회 × 3세트 |
| 5 | 맨몸 싱글레그 RDL | 좌우 8~12회 × 3세트 |
| 6 | 5kg 싱글레그 RDL | 좌우 10~15회 × 3세트 |
| 7 | 10kg 싱글레그 RDL | 좌우 8~12회 × 3세트 |

## 전용 워밍업
1. Cat-Cow 6~8회
2. 글루트 브리지 8~10회
3. 맨몸 힙힌지 10회
4. RDL 레벨이라면 5kg 덤벨 한 개로 5~8회 워밍업

## 초보자용 힙힌지 학습법
벽에서 약 20cm 떨어져 선다.

```text
무릎을 살짝 굽힘
→ 엉덩이를 뒤로 밀기
→ 엉덩이로 벽 터치
→ 다시 일어나기
```

핵심은 **허리를 숙이는 것이 아니라 고관절을 접는 것**이다.

## 세트 간 휴식
- 기본: 90~120초
- 느린 RDL / 싱글레그 RDL: 약 2분

## RDL 자세 핵심
- 덤벨을 몸 가까이 유지
- 무릎은 살짝 굽힌 상태 유지
- 엉덩이를 뒤로 이동
- 햄스트링이 늘어나는 지점까지 내려감
- 허리를 둥글게 말아 더 내려가지 않음

# 4.5 VERTICAL PUSH
## 목표 부위
- 어깨
- 삼두

## 장기 목표
덤벨 숄더프레스 → 파이크 푸시업 → 핸드스탠드 → HSPU

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 덤벨 숄더프레스 | 8~12회 × 3세트 |
| 1 | 높은 인클라인 파이크 푸시업 | 10~12회 × 3세트 |
| 2 | 파이크 푸시업 | 8~12회 × 3세트 |
| 3 | 발 높인 파이크 푸시업 | 6~10회 × 3세트 |
| 4 | 벽 핸드스탠드 홀드 | 30~45초 × 3세트 |
| 5 | 부분범위 벽 HSPU | 5~8회 × 3세트 |
| 6 | 벽 HSPU | 5~8회 × 3세트 |
| 7 | 프리 핸드스탠드 | 20~30초 |
| 8 | 프리 HSPU | 상급 목표 |

## 전용 워밍업
1. 어깨 작은 원 5회
2. 어깨 큰 원 5회
3. 벽 슬라이드 8~10회
4. 스캐풀라 푸시업 8회
5. 손목 전후 체중 이동 8~10회
6. 현재 운동의 쉬운 버전 5회

## 세트 간 휴식
- 덤벨 숄더프레스: 90~120초
- 파이크 푸시업: 약 2분
- HSPU 계열: 2~3분

## 주의사항
핸드스탠드 계열은 단순 근력뿐 아니라 균형과 기술을 요구한다.
다른 운동보다 레벨업 속도가 느려도 정상이다.

# 4.6 CORE
## 목표 부위
- 복직근
- 복횡근
- 복사근
- 몸통 안정성

## 장기 목표
기초 안정성 → 행잉 레그레이즈 → L-sit

| Lv | 운동 | 통과 기준 |
|---:|---|---|
| 0 | 데드버그 | 좌우 10회 × 3세트 |
| 1 | 플랭크 | 45초 × 3세트 |
| 2 | 할로우 바디 홀드 | 30초 × 3세트 |
| 3 | 행잉 니레이즈 | 10~12회 × 3세트 |
| 4 | 스트레이트 레그레이즈 진행 | 8~10회 × 3세트 |
| 5 | 행잉 레그레이즈 | 8~12회 × 3세트 |
| 6 | 푸시업바 Tuck L-sit | 20~30초 |
| 7 | L-sit | 20~30초 |

## 전용 워밍업
1. Cat-Cow 6회
2. 골반 기울이기(Pelvic Tilt) 10회
3. 버드독 좌우 5회
4. 행잉 운동 단계라면 발 보조 매달리기 10초 × 1~2회

## 세트 간 휴식
- 데드버그: 약 60초
- 플랭크 / 할로우홀드: 60~90초
- 행잉 니레이즈 / 레그레이즈: 90~120초
- L-sit: 90~150초

# 5. 세트 간 휴식 규칙

## 5.1 기본 휴식 가이드

| 세트 종료 후 상태 | 권장 휴식 |
|---|---:|
| 상당히 쉬움, 호흡 거의 정상 | 60~90초 |
| 근육에 확실한 자극 있음 | 90~120초 |
| 상당히 힘든 복합 운동 | 약 2분 |
| 풀업 / 불가리안 / HSPU 등 고강도 | 2~3분 |
| 아직 숨이 많이 차거나 자세 회복이 안 됨 | 추가 휴식 |

### 중요한 원칙
**타이머가 끝났다는 이유만으로 바로 다음 세트를 시작하지 않는다.**

다음 세트에서:
- 자세가 유지되고
- 목표 반복 수에 근접할 수 있고
- 호흡이 어느 정도 안정됐을 때

시작한다.

# 6. 반복 속도

초보자는 빠른 반복보다 **통제된 반복**을 우선한다.

## 기본 템포
### 스쿼트
```text
약 2초 내려감
→ 하단에서 짧게 정지
→ 1~2초에 올라옴
```

### 푸시업
```text
약 2초 내려감
→ 충분한 깊이
→ 약 1초에 밀어냄
```

### RDL
```text
2~3초에 걸쳐 내려감
→ 햄스트링 긴장 확인
→ 1~2초에 올라옴
```

정확한 초를 세는 것보다 **중력에 몸을 맡겨 떨어지듯 움직이지 않는 것**이 핵심이다.

# 7. 강도 조절: RIR

## 7.1 RIR 의미
RIR = Repetitions In Reserve

즉, 현재 세트를 끝냈을 때 **정확한 자세로 몇 회를 더 할 수 있었는지**를 의미한다.

예:

```text
10회 수행 후
"2회 정도 더 할 수 있었을 것 같다."
→ RIR 2
```

## 7.2 초보자 권장
대체로 **RIR 2~3**에서 종료한다.

### 피해야 할 패턴
```text
반복하다가 자세 완전히 무너짐
→ 억지로 한 번 더
→ 반동 사용
→ 더 이상 움직이지 못할 때까지 수행
```

초보 단계에서는 필요 없다.

# 8. 레벨업 판정

## 기본 규칙
레벨업은 단순히 한 번 성공했다고 이루어지지 않는다.

다음 순서로 판정한다.

1. 정확한 자세
2. 전체 또는 목표 가동범위
3. 목표 반복 수
4. 목표 세트 수
5. 마지막 세트에서도 RIR 약 1~2 확보
6. 다음 레벨 테스트

### 예시: 일반 푸시업 Lv.3
통과 기준: 10~15회 × 3세트

#### 초기
```text
8 / 6 / 5
```
→ 현재 레벨 적응 단계

#### 성장 중
```text
12 / 10 / 9
```
→ 유지

#### 거의 통과
```text
15 / 15 / 14
```
→ 다음 세션에서 재도전

#### 통과
```text
15 / 15 / 15
마지막 세트 RIR 1~2
자세 정상
```
→ Lv.4 디클라인 푸시업 테스트 가능

---

# 9. 다음 레벨이 너무 어려울 때

다음 단계로 올라갔는데 반복 수가 지나치게 적다면 **기존 레벨과 새 레벨을 섞는다.**

예:

현재 일반 푸시업 Lv.3 통과 후
디클라인 푸시업 Lv.4가 3회만 가능한 경우

```text
1세트: 디클라인 푸시업 3~5회
2세트: 일반 푸시업 10회
3세트: 일반 푸시업 10회
```

이후 디클라인 반복 수를 점진적으로 증가시킨다.

```text
3회
→ 4회
→ 5회
→ 6회
...
```

# 10. 점진적 과부하 규칙

중량을 올리는 것만이 점진적 과부하는 아니다.

아래 순서 중 하나 이상을 이용한다.

1. 반복 수 증가
2. 세트 수 증가
3. 가동범위 증가
4. 하강 속도 느리게
5. 특정 위치에서 정지
6. 한쪽 팔다리 사용
7. 더 어려운 운동 변형
8. 중량 증가

### 예: 하체
```text
맨몸 스쿼트
→ 5kg 고블릿 스쿼트
→ 10kg 덤벨 스쿼트
→ 10kg 느린 스쿼트
→ 리버스 런지
→ 불가리안 스플릿 스쿼트
→ 덤벨 불가리안
→ 박스 피스톨
→ 피스톨 스쿼트
```

# 12. 초보자에게 보여줄 핵심 규칙

화면 상단 또는 `운동 시작` 모달에서 아래 내용을 항상 노출한다.

> ### 오늘의 기본 규칙
> - 공통 워밍업부터 시작한다.

> - 본운동은 기본 3세트.
> - 쉬운 운동은 60~90초 휴식.
> - 일반적인 근력운동은 90~120초.
> - 풀업, 불가리안, HSPU 등 어려운 운동은 2~3분.
> - 매 세트 실패할 필요 없다.
> - 약 2회 더 할 수 있을 정도(RIR 2)를 목표로 한다.
> - 자세가 무너지면 반복 수보다 자세를 우선한다.
> - 목표를 안정적으로 달성하면 다음 레벨을 테스트한다.

# 13. 웹 기능 요구사항

## 13.1 필수 기능

### A. 운동 레벨 관리
각 운동 카테고리별로 현재 레벨을 독립적으로 저장한다.

예:
```json
{
  "push": 3,
  "pull": 1,
  "squat": 2,
  "hinge": 2,
  "verticalPush": 0,
  "core": 1
}
```

### B. 운동 기록
각 운동 세션마다 다음 내용을 저장한다.

```json
{
  "date": "2026-09-01",
  "category": "push",
  "level": 3,
  "exercise": "일반 푸시업",
  "sets": [
    {
      "reps": 12,
      "rir": 2
    },
    {
      "reps": 10,
      "rir": 2
    },
    {
      "reps": 9,
      "rir": 1
    }
  ],
  "pain": false,
  "note": ""
}
```

### C. 휴식 타이머
세트 종료 버튼을 누르면 권장 휴식시간을 자동으로 시작한다.

예:
- 기본 90초
- 풀업 120초
- 고급 운동 180초

사용자가 직접:
- +30초
- -30초
- Skip

가능하도록 한다.

### D. 레벨업 판정
마지막 세트 입력 후 자동 판정한다.

조건:
- 요구 세트 수 충족
- 각 세트 최소 반복 기준 충족
- 최고 반복 목표 달성 여부
- 마지막 세트 RIR 1~2 이상
- 통증 기록 없음

결과 예:

```text
Lv.3 진행 중
최근 기록: 15 / 15 / 14
다음 레벨까지 1회 남았습니다.
```

또는

```text
Lv.3 클리어!
다음 운동부터 Lv.4 디클라인 푸시업을 테스트할 수 있습니다.
```

### E. 성장 그래프
카테고리별로:
- 날짜별 반복 수
- 레벨 변화
- 총 운동량
- 최고 기록

을 확인할 수 있도록 한다.

# 19. Codex 구현 요청 요약

Codex에게 아래와 같이 전달하면 된다.

```text
이 문서를 기준으로 운동 초보자를 위한 홈트레이닝 성장형 웹앱을 만들어줘.

핵심은 운동 영상을 따라하는 서비스가 아니라,
PUSH / PULL / SQUAT / HIP HINGE / VERTICAL PUSH / CORE
6개 운동 패턴을 각각 독립된 스킬트리로 관리하고,
사용자가 초보 동작부터 고급 동작까지 레벨업하는 경험을 만드는 것이다.

사용자는 세트별 반복 수와 RIR을 기록하고,
세트 종료 시 휴식 타이머가 동작하며,
목표 기준을 만족하면 다음 레벨을 해금할 수 있어야 한다.

운동 시작 전에는 공통 워밍업과 각 운동별 전용 워밍업을 보여주고,
```

# 검증된 구현 오버라이드

이 섹션은 원본 기획서의 의학적 표현과 MVP 범위를 조용히 바꾸지 않기 위해 별도로 둔다. 위 원문은 공급된 요구사항으로 보존하고, 구현 시에는 아래 검증된 오버라이드를 우선 적용한다.

## 안전 및 의학적 표현

- 앱은 운동 기록과 진행 판단을 돕는 도구이며 의료 진단, 처방, 치료, 재활 판단을 제공하지 않는다.
- 흉통, 심한 어지럼증, 저림, 감각 이상, 날카로운 관절 통증, 갑작스러운 허리 통증은 운동 중단 신호로 취급한다.
- 중단 신호가 있으면 해당 운동을 계속 안내하지 않고 전문가 상담 또는 긴급 상황의 119 안내를 명확히 보여준다.
- 장비, 특히 문틈철봉은 안전을 보장한다고 표현하지 않는다. 사용 전 설치 상태, 허용하중, 흔들림 확인을 체크리스트로 안내한다.
- 사용자의 키, 체중, 상세 건강 답변은 브라우저 저장소에 저장하지 않는다. 저장 가능한 안전 상태는 최소한의 완료 여부와 시각 정보로 제한한다.

## 진행 규칙

- A/B/C 루틴은 달력 자동 스케줄이 아니라 사용자가 직접 완료할 때 다음 순서로 넘어가는 추천 시퀀스다.
- 최초 6회 완료 세션은 적응기로 보며 기본 2세트만 처방하고 레벨업 자격 세션으로 계산하지 않는다.
- 7번째 완료 세션부터 기본 3세트를 사용한다.
- 같은 카테고리에서 서로 다른 완료 세션 2개가 목표 기준을 만족해야 다음 레벨 테스트가 열린다.
- 실패한 테스트는 현재 레벨을 유지하며 사용자를 강등하지 않는다.
- 프리 HSPU는 터미널 목표로 취급하고 자동 승급 기준을 만들지 않는다.

## 데이터 및 백업

- LocalStorage 상태는 버전이 있는 스키마로 파싱한다.
- 손상된 저장소, 미래 버전, 잘못된 가져오기 파일은 현재 상태를 덮어쓰지 않는다.
- 복원은 미리보기 후 명시 확인이 있을 때 전체 교체로만 수행한다.
- 교체 전 현재 상태 백업 다운로드를 제공한다.

## 그래프 및 수치

- 반복 수, 초, 템포, 좌우 값, 중량은 서로 더하지 않는다.
- 그래프는 단위가 같은 원자료만 표시하고, 같은 정보를 표로도 확인할 수 있게 한다.
